## Enterprise Identity Governance & Automation Pipeline

<div align="center">
  <img src="assets/architecture-matrix.svg" alt="Enterprise Identity Governance &amp; AI Automation Pipeline" width="100%"/>
</div>

1. **Stage 01 — Authoritative HR Source:** Workday acts as the single source of truth for all employee and contractor lifecycles, streaming authoritative worker profile changes.
2. **Stage 02 — Reconciliation & Data Quality:** Custom Python ingestion engines reconcile incoming feeds against directory states, catching attribute drift and data gaps before provisioning.
3. **Stage 03 — Saviynt IGA Core:** Central governance policy engine executes automated JML workflows, enforces SOD rules, role assignments, and quarterly access certifications.
4. **Stage 04 — Enterprise Endpoints:** Automated provisioning to On-Premises Active Directory, Microsoft Entra ID, cloud workloads, and automated fulfillment of ServiceNow RITMs.
5. **Stage 05 — AI Governance & Verification:** Agentic workflows (`AI-Dev-Team`) inspect configuration health, audit policy drift, and accelerate engineering cycles via local and cloud LLMs.
